# week5- concept note
## 심층 신경망 (DNN)
* 심층 신경망은 여러 층의 뉴런으로 구성되어 데이터를 점진적으로 고차원 특징으로 변환
* 복잡한 문제를 해결하기 위해 각 층이 데이터를 비선형적으로 학습, 입력 데이터를 점차 추상화
* 활성화 함수와 다층 구조를 통해 비선형성과 학습 능력을 극대화

## 학습된 모델 재사용
* 일반적인 특징을 학습한 초기 층을 활용하고, 특정 작업에 맞는 출력층만 새로 학습
* 새로 학습시키는 것 보다 학습속도가 빠르며 학습에 필요한 dataset의 크기가 줄음
* 하지만 이전의 학습된 모델의 품질에 크게 의존

## 레이어 동결
* 레이어 동결은 특정 층의 가중치를 고정하여 학습 과정에서 변경되지 않게 하는 기법
* 초기 층의 일반적인 특징을 유지하고, 새로운 데이터에 맞는 고차원 특징만 추가로 학습
* 동결은 계산량을 줄이고 과적합을 방지하는 데 효과적

## 사용자 정의 손실 함수
* 모델의 예측값과 실제값 간의 오차를 정의해 문제에 맞게 정의 가능
* 후버손실은 작은 와는 MSE로 큰오차는 MAE로 정의

## 사용자 정의 층
* 직접초기화, 가중치 생성, 연산과정을 구연
* 초기화 메서드에서 층의 주요 속성 정의 후 call 메서드에서 입력 데이터 처리
* 기존충의로 구현할 수 없는 복잡한 계산을 수행가능
