# 그래디언트 클리핑

> Gradient Clipping

그래디언트 폭주(exploding gradient) 문제를 줄이기 위한 방법으로, 역전파 단계에서 그래디언트 값이 특정 임계값(threshold)을 넘지 않도록 잘라낸다.

# 심층 신경망 재사용

규모가 매우 큰 DNN 모델 학습 시 새로 학습하는 작업은 느리다. 이때 기존 학습된 모델이 존재하면 하위 층(lower layer)을 가져와 재사용하는 것이 학습 속도를 빠르게 하고 학습에 필요한 데이터 세트도 적다. 이러한 방법을 Transfer Learning이라고 한다.

이때 재사용에 사용하지 않을 층은 동결(freezing)하고, 사용할 층은 학습 가능한 상태로 유지한다. 동결된 층은 학습 과정에서 변하지 않으므로 가장 마지막에 동결된 층 출력을 캐싱하여 활용하면 학습 속도가 개선된다.

# 손실함수

모델의 예측 값과 실제 값 사이읭 오차를 계산한다.

## MSE

> Mean Squared Error

실제 값과 예측 값 사이 차이를 오차제곱합으로 계산, 평균을 내어 손실 함수를 구하는 방식.

오차가 더 큼에도 불구하고 더 좋은 평가를 받아 학습이 느려지거나 학습이 안 되는 상황이 발생하기도 한다.

## MAE

> Mean Absolute Error

오차가 작아도 선형적으로 오차를 평가하고 싶을 때 절대값으로 계산한다

## RMSE

> Root Mean Squared Error

큰 오차에 더 큰 패널티를 제시하는 방식으로 크기가 너무 커지면 더 큰 값이 나오므므로 루트를 취하는 방식으로 문제를 완화하였다.

## 후버 손실

MSE와 MAE의 장점을 결합하기 위해 작은 오차는 MSE를, 큰 오차는 MAE를 사용하는 함수.
